## Технический стек
- `index.html` — вся разметка, стили и логика (~1300 строк)
- `words.js` — только массив `BASE_WORDS` (1718 слов, ~140 КБ). Вынесен из index.html,
  чтобы диффы были читаемыми и правки кода не требовали греп-археологии по одной строке в 140 КБ
- `sw.js` — service worker, офлайн-кэш
- `manifest.json` + `icon-180/192/512.png` — PWA, иконка на домашнем экране
- Хостинг: GitHub Pages (ветка `main`, корень `/`)
- Деплой: `git push` → GitHub Pages обновляется автоматически за 1–2 минуты
- Firebase Authentication (email/password) + Firestore для облачного хранения прогресса
- Google Translate API для автоперевода при добавлении слов
- Никаких фреймворков, никакого сборщика — чистый JS, Firebase SDK через CDN

## Google Translate API
- Ключ лежит в `index.html`, константа `TRANSLATE_KEY`
- Ограничен HTTP referrer: `https://bershackln-judo.github.io/*`
- **Referrer-ограничение не защита** — заголовок подделывается одной строкой curl.
  Настоящая защита — жёсткая дневная квота в Google Cloud Console (Quotas)
- Ключ публичен (лежит в открытом репозитории). При подозрении на злоупотребление —
  ротировать в Google Cloud Console, а не прятать
- Поддерживает HU→RU и RU→HU
- Ответ прогоняется через `decodeEntities()`: Google возвращает HTML-сущности
  (`&#39;`, `&quot;`) даже при `format:'text'`

## Структура state (localStorage + Firestore)
```js
{
  settings: {
    wordSet: 'core' | 'full',      // Ядро (384) или Весь словарь (1718) — только в настройках ⚙
    direction: 'hu-ru' | 'ru-hu' | 'mixed',
    studyMode: 'dict' | 'custom',  // Словарь или Мои слова
    activeSetSize: 20              // Размер активного набора (10/15/20/30/50)
  },
  activeSet: {
    dict: [...],    // ключи слов в активном наборе для режима Словарь
    custom: [...]   // ключи слов в активном наборе для режима Мои слова
  },
  cards: {          // SM-2 данные по каждому слову
    'hu-word': { ivl, ease, reps, due }
  },
  learned: [...],   // ключи слов, отмеченных как «Изучено»
  custom: [         // добавленные пользователем слова
    { id, hu, ru, cat, pos }
  ],
  overrides: {},    // изменённые RU-переводы базовых слов { 'hu-key': 'новый RU' }
  overrides_hu: {}, // изменённые HU-написания базовых слов { 'hu-key': 'новый HU' }
  history: {},      // история повторений { 'YYYY-MM-DD': count }
  decks: [],        // не используется (убраны), остаётся для совместимости
  newIntroducedDate, newIntroducedCount
}
```

Ключи localStorage помимо состояния:
- `hu_was_signed_in` — был ли когда-то вход (нужно, чтобы отличить «облако отвалилось»
  от «пользователь никогда и не входил» и не пугать баннером зря)
- `hu_auth_skipped` — пользователь нажал «Продолжить без аккаунта», больше не спрашиваем

## Словарь
- 1718 слов в `words.js` как массив `BASE_WORDS = [[hu, ru, category, tier, pos], ...]`
- `tier > 0` — «ядро» (384 слова)
- 36 тем, дубликатов нет
- Части речи: сущ/гл/прил/нареч/местоим/числ/союз/предлог/частица/служ/фраза
- Счётчики в настройках считаются из `BASE_WORDS` на лету — не хардкодить их в вёрстке,
  разъезжаются

## Хранение и синхронизация
- **localStorage — источник правды при старте.** Приложение рендерится из него
  синхронно, до всякой сети (`loadLocalState`). Firebase подключается вторым шагом
- **Firebase не обязателен.** Инициализация в `try/catch`, флаг `firebaseReady`.
  Если SDK не загрузился (офлайн, gstatic заблокирован) — приложение работает целиком
  локально. Раньше здесь был `await` на Firebase, и без сети получался белый экран
- **Запись в Firestore с дебаунсом** `CLOUD_SAVE_DELAY = 2500` мс. Документ уходит
  целиком (~130 КБ при полном словаре), слать его на каждую оценку карточки — дорого.
  Досылка принудительно на `visibilitychange`, `pagehide` и `online`
- **Ошибки синхронизации видны пользователю** — жёлтый баннер `#syncBanner` под шапкой.
  `console.error` недостаточно: на айфоне консоль никто не смотрит, и молчаливый отказ
  облака выглядит как «всё в порядке» ровно до потери данных
- **Конфликт двух устройств не решается** — последняя запись побеждает, документ
  перезаписывается целиком. Для одного пользователя приемлемо, но знать надо

## Функционал

### Вкладка «Учить»
- **Активный набор**: в работе всегда N слов (по умолчанию 20). Слова повторяются по SM-2 пока вручную не нажмёшь «Изучено». Как только слово уходит — на его место приходит следующее
- **Два режима** (чипы вверху, НИКОГДА не смешиваются):
  - **Словарь** — встроенные слова
  - **Мои слова** — только добавленные вручную
- **Чип направления**: простой тоггл HU→RU ↔ RU→HU (только два состояния). Режим «Вперемешку» доступен только через настройки ⚙
- **Прогресс**: «В работе: N» — просто количество слов в активном наборе
- **Кнопка 🔊** на каждой карточке — озвучивает венгерское слово через Web Speech API (`hu-HU`). Всегда озвучивает `w.hu` независимо от направления
- **Оценки карточки**: Снова / Трудно / Хорошо / Легко (SM-2). Подписи с интервалами
  считаются из состояния карточки (`previewHard`, `previewInterval`) — не хардкодить
- **Кнопка «Изучено — больше не показывать»**: убирает слово навсегда
- **Экран «Готово 👏»**: кнопка **«Позаниматься ещё раз»** — практический проход без изменения `due`/`ivl`. Флаг `practiceMode = true`, сбрасывается в `buildQueue()` и при повторном появлении экрана «Готово»
- **Кнопка ＋** в заголовке → быстрое добавление слова с автопереводом

### Вкладка «Слова»
- Фильтры со счётчиками: **Все (N)** / **Мои слова (N)** / **Изучено (N)**
- Поиск по венгерскому и русскому
- **Список рисуется порциями** по `PAGE_SIZE = 60` + кнопка «Показать ещё».
  Раньше при каждом нажатии клавиши перестраивались все 1718 элементов с тысячами
  обработчиков — на айфоне это заметно тормозило
- **Клики ловятся одним делегированным слушателем** на `#wordsList`, не на каждой кнопке
- **Тап на слово** (не на кнопки) → шторка-просмотр: венгерское слово крупно, перевод, 🔊
- **Кнопка «Изменить перевод»** → шторка с полями «Венгерский» и «Русский»
- Кнопки «Изучено» / «Учить снова» у каждого слова
- Удаление — только своих слов

### Вкладка «Статистика»
- Три счётчика: Слов в наборе / Начато / Изучено — все считаются в границах выбранного
  набора, иначе числа не бьются друг с другом
- График повторений за 14 дней
- Разбивка прогресса по темам

### Настройки (шестерёнка ⚙)
- Набор слов: Ядро / Весь словарь (числа подставляются из `BASE_WORDS`)
- Слов в активном наборе: 10 / 15 / 20 / 30 / 50
- Направление перевода
- Скачать / Загрузить резервную копию (JSON)
- Сбросить весь прогресс
- Раздел «Аккаунт»: email, кнопка «Выйти»

### Firebase аутентификация
- При первом запуске — шторка «Сохранение прогресса»
- Варианты: зарегистрироваться / войти / продолжить без аккаунта
- **«Забыли пароль?»** → `sendPasswordResetEmail`. Поэтому email должен быть настоящим:
  без него доступ к облачному прогрессу не восстановить
- Вошёл → прогресс в Firestore + localStorage (кэш)
- При первом входе — localStorage выгружается в облако
- Отказ от входа запоминается (`hu_auth_skipped`) — шторка не спрашивает каждый запуск

### PWA / офлайн
- `sw.js` — стратегия **network-first с откатом в кэш**: пока есть интернет, отдаётся
  свежая версия (значит обычный `git push` доезжает до телефона без возни с версиями
  кэша), без интернета — последняя сохранённая
- Навигационные запросы имеют таймаут `NAV_TIMEOUT_MS = 3000` — иначе при «интернет
  есть, но не работает» экран висит бесконечно
- Кросс-доменные запросы (Firebase, Google Translate) service worker не трогает
- `CACHE = 'hu-words-v1'` — константа для очистки старых кэшей при активации

## Важные решения (не менять без явного запроса)
- **Нет лимитов новых слов** — система активного набора решает это иначе; новые слова сначала из ядра (tier > 0), потом остальные
- **Нет теста с вариантами** — убрали, не возвращать
- **«Изучено» — вручную ИЛИ автоматически** при устойчивом интервале ≥ 21 дня (константа `GRADUATE_IVL_DAYS` в `gradeCard`)
- **Нет колод** — убраны, заменены двумя режимами
- **Нет фильтра по частям речи** на обоих экранах — убран
- **Нет формы добавления на вкладке «Слова»** — только кнопка ＋ в заголовке
- **Чип «Ядро/Все слова» только в настройках** — убран с главного экрана
- **Чип направления — только 2 состояния** (hu-ru ↔ ru-hu), не возвращать 3-позиционный цикл с mixed
- **overrides_hu** — ключ всегда оригинальный HU из BASE_WORDS, не изменённый (это индекс в cards/learned/activeSet). При сохранении сравнивается с оригиналом: совпадает — override удаляется, отличается — сохраняется
- **overrides (RU)** — то же правило: сравнивается с `BASE_WORDS[n][1]`, а не с текущим `w.ru` (который уже может быть override)
- **`state.learned` дублируется в `learnedSet`** (Set) — проверки идут через `isLearned()`,
  мутации только через `markLearned()` / `unmarkLearned()`. Массив остаётся, потому что
  он сериализуется в JSON; Set нужен, чтобы не делать `includes` по массиву внутри
  циклов на 1718 слов. **Не менять `state.learned` напрямую** — рассинхронизируется
- **Импорт бэкапа идёт через `applyLoadedState`** — не дублировать нормализацию

## Как делать изменения
1. Редактируй `/Users/nikitabershack/cards app/index.html` (словарь — в `words.js`)
2. Перед правкой JS — грепай по всему файлу
3. После правки JS — проверяй синтаксис:
   ```bash
   cd "/Users/nikitabershack/cards app"
   s=$(grep -n '^<script>$' index.html | cut -d: -f1)
   e=$(grep -n '^</script>$' index.html | cut -d: -f1)
   sed -n "$((s+1)),$((e-1))p" index.html | node --check
   node --check words.js && node --check sw.js
   ```
4. Деплой:
   ```bash
   cd "/Users/nikitabershack/cards app"
   git add -A && git commit -m "..." && git push
   ```
5. На айфоне после деплоя: если приложение добавлено на домашний экран, service worker
   отдаёт свежую версию при первом запуске с интернетом. Если что-то залипло —
   Настройки → Safari → Очистить историю, либо в вкладке снять с домашнего экрана и добавить заново

## Известные риски
- Номера строк меняются при каждом редактировании — всегда пересчитывай
- Слияния между двумя устройствами нет: кто последний сохранил, того и состояние
- `state.history` растёт бесконечно и никогда не чистится
- Web Speech API: голос `hu-HU` есть не на всех устройствах; если его нет,
  система читает венгерский чужой фонетикой либо молчит. Молча, без ошибки
- Своим словам жёстко проставляется `cat: 'Мои слова'`, `pos: 'сущ'` —
  для глаголов и прилагательных подпись будет неверной
- Дубликаты при добавлении своих слов не проверяются
