## Функционал

### Вкладка «Учить»
- **Активный набор**: в работе всегда N слов (по умолчанию 20). Слова повторяются по SM-2 пока вручную не нажмёшь «Изучено». Как только слово уходит — на его место приходит следующее
- **Два режима** (чипы вверху, НИКОГДА не смешиваются):
  - **Словарь** — встроенные слова
  - **Мои слова** — только добавленные вручную
- **Чип направления**: простой тоггл HU→RU ↔ RU→HU (только два состояния). Режим «Вперемешку» доступен только через настройки ⚙
- **Прогресс**: «В работе: N» — просто количество слов в активном наборе, без дробей и счётчика сессии
- **Кнопка 🔊** на каждой карточке (правый нижний угол) — озвучивает венгерское слово через Web Speech API (`hu-HU`). Всегда озвучивает `w.hu` независимо от направления
- **Оценки карточки**: Снова / Трудно / Хорошо / Легко (SM-2 алгоритм)
- **Кнопка «Изучено — больше не показывать»**: убирает слово навсегда (только вручную)
- **Экран «Готово 👏»**: кнопка **«Учить заново»** сбрасывает due-даты и начинает заново
- **Кнопка ＋** в заголовке → быстрое добавление слова с автопереводом

### Вкладка «Слова»
- Фильтры со счётчиками: **Все (N)** / **Мои слова (N)** / **Изучено (N)**
- Поиск по венгерскому и русскому
- **Тап на слово** (не на кнопки) → шторка-просмотр: венгерское слово крупно, перевод, кнопка 🔊
- **Кнопка «Изменить перевод»** → шторка с двумя полями: «Венгерский» и «Русский»
  - Для **своих слов**: сохраняет `c.hu` и `c.ru` напрямую
  - Для **базовых слов**: сохраняет в `state.overrides_hu[key]` (HU) и `state.overrides[key]` (RU)
- Кнопки «Изучено» / «Учить снова» у каждого слова
- Удаление — только своих слов

### Вкладка «Статистика»
- Три счётчика: Активно / Начато / Изучено
- График повторений за 14 дней
- Разбивка прогресса по темам

### Настройки (шестерёнка ⚙)
- Набор слов: Ядро (384) / Весь словарь (1718)
- Слов в активном наборе: 10 / 15 / 20 / 30 / 50
- Направление перевода
- Скачать / Загрузить резервную копию (JSON)
- Сбросить весь прогресс
- Раздел «Аккаунт»: email, кнопка «Выйти»

### Добавление слова (кнопка ＋)
- Шторка «Новое слово»
- Поле «Венгерский» + кнопка «Перевести» → HU→RU через Google Translate
- Поле «Русский перевод» + кнопка «Перевести» → RU→HU через Google Translate
- После добавления — автопереход в режим «Мои слова»

### Firebase аутентификация
- При первом запуске — шторка «Сохранение прогресса»
- Варианты: зарегистрироваться / войти / продолжить без аккаунта
- Вошёл → прогресс в Firestore (фон) + localStorage (кэш)
- Не вошёл → только localStorage
- При первом входе — localStorage автоматически выгружается в облако
- Позже: шестерёнка → Аккаунт → Войти / Создать аккаунт

## Важные решения (не менять без явного запроса)
- **Нет лимитов новых слов** — система активного набора решает это иначе
- **Нет теста с вариантами** — убрали, не возвращать
- **«Изучено» только вручную** — никакой автоматики
- **Нет колод** — убраны, заменены двумя режимами
- **Нет фильтра по частям речи** на обоих экранах — убран
- **Нет формы добавления на вкладке «Слова»** — только кнопка ＋ в заголовке
- **Чип «Ядро/Все слова» только в настройках** — убран с главного экрана
- **Чип направления — только 2 состояния** (hu-ru ↔ ru-hu), не возвращать 3-позиционный цикл с mixed
- **Firestore fire-and-forget** — не блокирует UI при медленном интернете
- **overrides_hu** — ключ всегда оригинальный HU из BASE_WORDS, не изменённый (это индекс в cards/learned/activeSet)
