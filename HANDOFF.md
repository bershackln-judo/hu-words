## Функционал

### Вкладка «Учить»
- **Активный набор**: в работе всегда N слов (по умолчанию 20). Слова повторяются по SM-2 пока вручную не нажмёшь «Изучено». Как только слово уходит — на его место приходит следующее из очереди
- **Два режима** (чипы вверху):
  - **Словарь** — встроенные слова, доп. чип Ядро/Все слова
  - **Мои слова** — только добавленные вручную слова
  - Режимы НИКОГДА не смешиваются, у каждого своя очередь и свой активный набор
- **Чип направления**: HU→RU / RU→HU / Вперемешку
- **Прогресс**: «В работе: 20/20» + счётчик сессии
- **Оценки карточки**: Снова / Трудно / Хорошо / Легко (SM-2 алгоритм)
- **Кнопка «Изучено — больше не показывать»**: убирает слово из очереди навсегда (только вручную)
- **Экран «Готово 👏»**: когда все слова пройдены, кнопка **«Учить заново»** сбрасывает due-даты и начинает заново
- **Кнопка ＋** в заголовке → быстрое добавление слова с автопереводом

### Вкладка «Слова»
- Поиск по венгерскому и русскому
- Фильтры: Все / Мои слова / Изучено (N)
- Фильтр по части речи
- Добавление своих слов (форма: hu, ru, тема)
- Редактирование перевода любого слова (включая базовые — через state.overrides)
- Удаление — только своих слов
- Кнопки «Изучено» / «Учить снова» у каждого слова

### Вкладка «Статистика»
- Три счётчика: Активно / Начато / Изучено
- График повторений за 14 дней
- Разбивка прогресса по темам

### Настройки (шестерёнка ⚙)
- Набор слов (Ядро / Весь словарь)
- Слов в активном наборе (10 / 15 / 20 / 30 / 50)
- Направление перевода
- Скачать / Загрузить резервную копию (JSON)
- Сбросить весь прогресс
- Раздел «Аккаунт»: показывает email, кнопка «Выйти»

### Firebase аутентификация
- При первом запуске — шторка «Сохранение прогресса»
- Можно зарегистрироваться (email + пароль, любой email), войти или «Продолжить без аккаунта»
- Если вошёл: прогресс пишется в Firestore (в фоне, не блокируя UI) + localStorage как кэш
- Если не вошёл: только localStorage
- При первом входе с существующим localStorage — прогресс автоматически выгружается в облако
- Войти позже: шестерёнка → Аккаунт → Войти / Создать аккаунт

### Добавление слов с автопереводом
- Кнопка ＋ в заголовке → шторка «Новое слово»
- Поле «Венгерский» + кнопка «Перевести» (HU→RU через Google Translate)
- Поле «Русский перевод» + кнопка «Перевести» (RU→HU через Google Translate)
- После добавления — автоматический переход в режим «Мои слова»
- Перевод работает только при наличии интернета

## Важные архитектурные решения (не менять без явного запроса)
- **Без лимитов новых слов** — заменено системой активного набора
- **Нет режима теста с вариантами** — убрали, не возвращать
- **«Изучено» только вручную** — нет автоматики по интервалам
- **Firestore пишется в фоне** (`fire and forget`) — не блокирует UI при медленном интернете
- **Нет колод** — убраны, заменены двумя режимами
- **Нет фильтра по частям речи** на экране учёбы — убран
- **Анонимная авторизация** — не использовалась (привязана к браузеру, не решает проблему)
